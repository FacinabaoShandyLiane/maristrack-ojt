# 💳 MarisTrack

A responsive front-end interface developed as part of my internship at Notre Dame of Marbel University for the Office of Admissions, Promotions, and Scholarships.

> **Note:** This repository contains only the front-end implementation. The back-end code and database are not included because they were part of the organization's internal system.

---

## 📖 Overview

MarisTrack is a web-based attendance monitoring system developed for the NSTP Office of Notre Dame of Marbel University.

During my internship, I contributed to the project's front-end development, UI/UX design, quality assurance testing, and documentation while collaborating with the development team.

---

## 👩‍💻 My Contributions

- Developed responsive user interfaces
- Implemented pages using HTML, CSS, JavaScript, and Tailwind CSS
- Collaborated on UI/UX design using Figma
- Assisted in usability testing
- Documented system improvements and issues
- Worked closely with the backend developer during development
